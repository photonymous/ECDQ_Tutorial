Dither, but without the compression penalty An interactive tutorial of ECDQ dither synchronization, answering the following questions: Why does intentionally adding noise (dither) improve the quality of quantized data? Why does a naive implementation of dither harm data compressability? and How does synchronized rounding of dithered data eliminate most of that harm?

This tutorial is about storing or transmitting a signal (1D data like audio, 2D data like images, 3D data like flow velocities, etc.) using fewer bits. The process has two stages. First, quantization rounds each value to a coarse grid; this is the only step that discards information, and the amount of quantization is the knob that determines the quality vs. bit-rate tradeoff. Then, the quantized samples are compressed losslessly, using prediction: estimate each sample from its already-decoded neighbors, and store only the difference between the estimate and the truth. Quantization has an undesirable side effect: the error it introduces is a function of the signal, producing structured artifacts. A standard mitigation is to add dither, which deliberately adds a small random offset before rounding. This transforms the error from structured to unstructured. However, dither adds energy (entropy) and thus decreases the predictability of a predictive entropy encoding (compression) scheme. This is because the random offsets push what would otherwise be accurate predictions off the rounding grid causing the bit rate after compression to increase. Entropy-constrained dithered quantization (ECDQ) gets the benefits of subtractive dither (reduction in quantization-induced structured error) error while mitigating the bit-rate impact. This tutorial introduces and demonstrates ECDQ piece by piece.

The central idea can be expressed in a single line:

pq = round( p / Δ + d[n] )

Here p is the prediction, Δ is the grid spacing, d[n] is the dither value for sample n, and the result pq is the prediction, quantized. Before rounding a prediction, add the same dither value used for the true sample at that position. The sections below explain why this keeps the two rounding operations synchronized.

What ECDQ contributes. An entropy-constrained dithered quantizer (ECDQ) combines subtractive dither, prediction, and entropy coding. Shared dither makes quantization error independent of the input; applying the same dither when the prediction is rounded keeps accurate predictions cheap to encode. The tutorial develops those two ideas separately and then joins them in a closed prediction loop. ECDQ comes from the universal-quantization literature: Ziv introduced the construction [3], and Zamir and Feder developed its theory and gave it the name [5, 6].

How to use this page. Every figure is interactive, and every number is computed live in your browser from the equations presented here; nothing is fetched or precomputed. Try the sliders and switches to see how the results change.

These are toy models, not performance predictions. Every plotted signal is synthetic and one-dimensional. More importantly, the selectable predictors are tiny, causal 1D examples: previous-sample prediction, a four-sample average, and a four-sample linear predictor (extrapolator). They were chosen to make the arithmetic clear, not because they represent the best algorithms.

Non-causal and higher-dimensional applications can use a neighborhood of samples surrounding each sample being predicted, giving better prediction performance. Such predictors will have different residual entropies, zero rates, dither penalties, and whether and where the rate curves cross. The specific numerical values shown here are therefore not directly predictive of the non-causal or higher-dimensional cases. However, the key phenomena generalize: undithered quantization creates signal-dependent structured error; naive dither can reduce the error structure at the expense of increased entropy; ECDQ aligns rounding thresholds to reduce the entropy.

SECTION 1Rounding error is not white noise

A quantizer takes a continuous value and forces it to the nearest point on a fixed lattice. The lattice spacing is Δ, or one least significant bit (LSB). Fewer quantization levels require fewer bits, and predictive coding can reduce the rate further when adjacent samples are correlated (similar to each other).

The error is at most half of an LSB, but its size alone is misleading because the error is a deterministic function of the signal. It is not noise. If the quantizer is fed the same value twice, it will produce the same error twice. This correlated error is a distortion that shows up as banding in images, harmonics in audio, and structured artifacts in numerical data.

There is one important exception. If the signal is much smaller than a quant-step, the undithered error is small in RMS simply because the output gets rounded to a constant zero and the error becomes the signal itself. The RMS is low even though the signal has been completely lost. The next figure shows why RMS is not a useful measure in that case.

SECTION 2Dither: adding noise to improve signal quality

Subtractive dither employs one extra term inside the rounding operation, and one matching subtraction on the decoding side:

q[n] = round( x[n] / Δ + d[n] ) // encode, with d[n] uniform on [-0.5, +0.5)
y[n] = ( q[n] - d[n] ) × Δ // decode, subtract the same d[n]

Because the same d[n] is subtracted (removed), this is called subtractive dither, an idea introduced by Roberts in 1962 [1], with the conditions on d[n] established by Schuchman [2] and the theory surveyed by Lipshitz, Wannamaker, and Vanderkooy [4]. It requires that the decoder can regenerate d[n] exactly, which is easy: both sides run the same hash or PRNG (pseudo-random number generator) on the sample index and a shared seed. No dither values are ever transmitted.

With d[n] uniform on [-0.5, +0.5), the encode step is exactly stochastic rounding: a value lands on the grid point above it with probability equal to its fractional distance to that point, and below otherwise, so the rounded value is correct on average (unbiased). This uniform width-one distribution matters; a narrower, wider, or non-uniform d[n] would not give the exact probabilities, and the independence result below would fail. Every dithered figure on this page draws d[n] from this distribution.

Combining these equations gives y[n] = x[n] + e[n]Δ where e[n] is the rounding residue. With uniform d the quantity e[n] is uniform on [-0.5, 0.5) and statistically independent of x[n], provided the quantizer does not clip. The error stops being a function of the signal and becomes genuine additive noise. Digital dither uses a close approximation to this ideal distribution.

Information below the LSB survives

If a signal is smaller than one quantization step, plain rounding can round it to zero, destroying it. Dithered rounding preserves it instead. The signal is still there, encoded in how often the output flips between levels, and averaging can recover the signal lurking beneath the noise.

Distortion is whitened

Without dither, the quantizer produces harmonics that were not present in the input, and a tone below half an LSB disappears entirely. With dither, the original peak remains, and the harmonics are spread out uniformly (whitened) to create a broad-band noise floor. For moderate and large signals the total error energy is often similar, but its distribution is very different. For a small signal the undithered RMS can be lower because the output has collapsed to all zeros (or mostly zeros).

In applications where dither cannot be subtracted during reconstruction, the dither noise remains. Rectangular dither decorrelates the quantization error from the signal (removes the bias imparted on the signal), but the magnitude of the error (not the sign) remains dependent on the signal. A solution to this is to use a triangular distribution for the dither instead. This removes the magnitude dependence, but results in a total noise power three times that of the subtractive case (about 4.8 dB more). Subtractive dither avoids that extra cost in applications where the encoder and decoder can both generate the same dither sequence.

SECTION 3Predictive coding and residual entropy

So far the focus has been signal quality. For compression, the useful fact is that many signals are locally correlated, so nearby samples tend to be similar. A predictive coder estimates each sample from values it has already decoded and stores only the correction.

p = predict( y[n-K] .. y[n-1] ) // the prediciton, from previously decoded values
pq = round( p / Δ ) // the prediciton, quantized to the integer grid
r[n] = q[n] - pq // the residual: this is what gets stored

The decoder receives the residual stream r[n], recomputes the identical prediction from its own copy of the already decoded values, and recovers the quantized version of the signal q[n] = pq + r[n]. Encoder and decoder run the same loop and stay in lockstep. This is a closed loop coder: the predictor must feed on reconstructions, never on originals, because reconstructions are all the decoder has access to.

This has two practical consequences.

  • The residual histogram gives a useful first estimate of file size. If each residual is treated independently, its ideal average cost (entropy) is H = -Σ p·log2(p) bits. This is not a hard lower bound for the whole stream: a compressor can do better when it finds predictable runs and patterns.
  • Long runs of zeros are especially cheap. A residual stream that is 85% zeros often costs well under one bit per sample. Replacing many of those zeros with a mix of -1, 0 and +1 usually makes both the histogram and the sequence harder to compress.

SECTION 4Why naive dither hurts compression

Dither provides the signal-quality benefits shown in Section 2, while predictive coding benefits from a residual stream dominated by zeros (or very small values). A naive implementation allows dither to balloon the entropy of the residual stream.

Consider a sample where the predictor is perfect: the prediction p equals the true value x[n] exactly. Without dither the residual is exactly zero, as it should be. With dither:

q[n] = round( x[n]/Δ + d[n] ) // rounded with a random threshold offset
pq = round( p/Δ ) // rounded on the plain grid
r[n] = q[n] - pq // = 0 or ±1 at random, despite a perfect prediction

The dither shifts the sample's rounding threshold but not the prediction's, so the two often round to different integers. Across a sequence, even a perfect predictor lands on the wrong integer for about a quarter of samples, and a less accurate one does worse. Flat regions that would have produced long runs of zero-residuals now contain a mixture of -1, 0, and +1, increasing the entropy of the residual even though the prediction itself is accurate.

SECTION 5Synchronized rounding

Figure 5 shows the central mechanism using a number line example.

Rounding partitions the number line into cells. round(v) = k exactly when v lies in the cell [k-0.5, k+0.5). Adding a dither d before rounding is equivalent to sliding every decision threshold left by d while leaving the value in place.

If the true value and the prediction use the same set of thresholds, nearby values usually land in the same cell and produce a zero residual. The absolute positions of the thresholds do not matter. Use the dither slider below to see this directly.

In naive mode the top lane's thresholds slide with d while the bottom lane's remain fixed. Move the prediction toward the true value and watch P(r ≠ 0): it does not improve. Reducing the prediction error from 0.4 LSB away to 0.05 LSB away changes that probability by nothing at all. It is pinned at whatever fraction of the dither's range happens to land outside the prediction's cell, which is a fact about where x sits relative to a fixed threshold, and has no relationship to prediction quality. Push the prediction past a threshold and the probability changes abruptly; it can become very large, and in one direction it can reach 100 percent.

Across a sequence, this leaves about a quarter of residuals nonzero even with a perfect predictor. The bits spent on residuals are determined by where the samples happen to sit relative to the rounding thresholds, not by how close the predictions come to the truth. A highly accurate predictor would therefore produce a similar bit rate to a mediocre predictor, violating expectation.

Switch to ECDQ and both lanes receive the same threshold shift. Sweep d through its whole range and the residual stays pinned at zero, except in a narrow band where a threshold happens to fall between the two values. Move the prediction slider again and compare the last two readouts, which now track each other digit for digit:

P(r ≠ 0) = |x - p| / Δ, exactly, for any prediction closer than one step. The probability of a nonzero residual depends only on prediction accuracy, not on the dither.

There is a second part to ECDQ. The predictor should not receive q·Δ, which still contains the dither offset; it should be fed the de-dithered reconstruction y = (q - d)·Δ. Its remaining error is centered on zero, has a fixed noise power, and is unrelated to the signal. That makes it a more consistent predictor input and often reduces |x - p|, which in turn reduces the residual entropy. ECDQ therefore has two parts:

  • Dither injection: add the dither d[n] before rounding the prediction, just as it is added before rounding the true sample. This aligns the thresholds and removes the synchronization penalty.
  • De-dither: predict from (q - d)·Δ rather than q·Δ. This improves the prediction and can eliminate or greatly reduce the entropy penalty of dither.

With the default four-tap predictor, naive dither has the highest entropy. De-dithering alone helps very little: it gives the predictor a more accurate input, but the result is still rounded against the wrong thresholds. Dither injection alone recovers most of the loss. Only the combination of both is ECDQ, and it comes close to the no-dither baseline while retaining the signal-quality benefits from Section 2.

Dither injection and de-dithering are not independent

Change the predictor to previous sample. The naive, de-dither-only, and inject-d[n]-only bars become exactly equal. A single-tap predictor reading reconstructions that have not been de-dithered computes p = y[n-1] = q[n-1]·Δ. Divide by Δ and that is an exact integer. The dither is always smaller than half a step, so adding it never moves the value across a rounding threshold: the result rounds back to the same integer it started on. Injecting the dither therefore has no effect.

Dither injection can only help when the prediction lands between levels. What puts it between levels is de-dithering, which turns integer reconstructions into fractional ones. In the 4 tap case averaging four integers does some of that work too, which is why dither injection alone already helps there. The two components of ECDQ are therefore coupled: dither injection aligns thresholds, while de-dithering allows the prediction to fall between quantization levels.

The four-tap linear extrapolator fits a straight line to y[n-4]..y[n-1] and evaluates it at n. Its least-squares weights are equivalent to p = -0.5y[n-4] + 0.5y[n-2] + y[n-1]; the coefficient of y[n-3] cancels after the fit. Because these weights are fractional, the prediction can land between levels even without de-dithering, so dither injection alone can help. The complete ECDQ loop still uses both components: de-dithering removes past offsets and dither injection aligns the current rounding thresholds.

SECTION 7The remaining cost of dither, and how it fades

At coarse quantization, ECDQ approaches the undithered baseline but does not quite reach it. The remaining difference comes from the quiet zone.

In regions where most samples are below one quant step, without dither, the low-amplitude samples round to zero, the predictor returns zero, and long runs of residuals cost almost nothing (the "quiet zone"). Dither maps these near-zero samples to 0 or ±1, producing occasional nonzero residuals. These extra bits are not waste of the kind Section 4 showed, where unsynchronized dither generated residuals that described only the dither itself. Here, whether a sample rounds to 0 or to ±1 depends on its actual sub-step amplitude, so the residuals record detail about the signal that plain rounding would have flattened to a run of zeros.

The cost depends on how much of the signal lies in the quiet zone, which shrinks quickly as resolution improves. At the same time, de-dithered reconstructions improve the prediction. So as the grid gets finer, two things happen at once: fewer samples are small enough to sit in the quiet zone, so the nonzero residuals that dither produces there (where undithered coding would emit a run of zeros) become rare and their entropy cost fades; and the predictor, fed on de-dithered history that resolves detail between grid levels, keeps getting more accurate relative to the step size, which makes dithered residuals cheaper to code. The rate gap between the dithered and undithered coders therefore narrows; in this toy setup the curves eventually meet and can even trade places.

What does generalize is the competition itself: at coarse resolution, dither pays an entropy cost for the quiet-zone detail it preserves; as resolution increases, synchronized dither and de-dithered history let accurate predictions once again produce small residuals that the entropy coder represents in fewer bits, and that benefit gradually cancels the cost.

At coarse resolution, undithered coding is cheaper because it turns quiet regions into long runs of zeros. Where the curves cross, the dithered stream is momentarily the smaller one even though it retains more information. At higher bit depths the curves remain close. Which one is slightly lower depends mostly on the incidental alignment between the signal and the quantization grid. Moving the gain slider can reverse the ordering, showing that the two costs have effectively converged.

As Δ gets smaller, the predictor's ordinary error spans many increasingly fine quantization steps. The small change caused by randomized rounding then becomes tiny compared with the error already present in the prediction. Both residual histograms approach sampled versions of the same continuous prediction-error distribution, so their compression costs converge. Once they are very close, small details such as signal alignment and finite sample count can decide which curve is slightly lower.

Subtraction removes the added dither energy itself, but it cannot undo the rounding. The remaining rounding noise is carried in past reconstructions and therefore enters later predictions. That is why a small difference can remain at finite resolution and why the two curves eventually converge and sometimes even trade places.

SECTION 8Implementation and bit-exactness

This tutorial treats the signal x[n], the dither d[n], and the reconstruction y[n] as continuous quantities, which in code would ordinarily become floating-point numbers. But this hides a practical requirement. In a closed prediction loop, the predictor feeds on reconstructions, so the encoder and the decoder must compute bit-identical y[n] values, on every sample, forever. If floating-point arithmetic on the two sides differs by even one unit in the last place (a different math library, a compiler that fuses a multiply-add, a reordered summation in the predictor), a round() near a threshold can land on a different integer. That changes pq, which changes y[n], which corrupts the history every later prediction reads. The decoder drifts away from the encoder and never recovers. This is the same class of failure this page attributes to naive dither, two rounding operations falling out of agreement, except caused by the arithmetic itself.

The remedy used by production lossless and near-lossless coders is to define every operation inside the loop using integers, where arithmetic is exact on every platform. Represent the input at a finer integer scale: let X be an integer at resolution Δ/2K, so K extra bits stand in for the continuous value. Sample each dither value as an integer u[n] uniform on the range {0, …, 2K-1} from an integer PRNG (the generator used by this page is already pure integer arithmetic). Dithered quantization then collapses to an add and a shift:

q[n] = ( X[n] + u[n] ) >> K

This is exactly round(x/Δ + d) with d = (u + ½)/2K - ½: a finite, uniform width-of-one dither, with no floating point anywhere. The reconstruction is kept as an integer at the same fine scale, Y[n] = q[n]·2K - u[n] plus a constant half-step offset, and is never converted to floating point inside the loop. The predictor is likewise defined over integer Y with integer coefficients and a specified rounding rule for its divisions, which is how the predictors in formats such as FLAC and JPEG-LS are specified. Every quantity in the loop is then rigorously defined, and encoder–decoder agreement is guaranteed by construction.

The figures on this page are exempt from this concern only because their encoder and decoder are the same computation running in the same arithmetic engine, so they cannot disagree with themselves. You may interpret the continuous-valued equations here as exact arithmetic; build them as integer arithmetic, not as floats.

SECTION 9Summary

Uniform subtractive dither converts deterministic, signal-dependent quantization distortion into approximately additive, input-independent noise, provided the quantizer does not clip. This removes structured artifacts and preserves information below one quantization step, while keeping the error power bounded and predictable.

In a predictive coder, applying dither to only the sample shifts the decision thresholds relative to the thresholds used for the prediction. Even an accurate predictor can then produce unnecessary nonzero residuals, increasing residual entropy. ECDQ avoids this mismatch by applying the same dither value to both rounding operations, so their thresholds move together. And because the decoder knows the dither sequence too, predictions on both sides can be based on de-dithered reconstructions. Prediction accuracy, not randomness, then determines the sparsity of the residual stream (and thus the entropy and compression rate).

A genuine compression rate tradeoff remains at coarse resolution. Dither preserves sub-LSB information in quiet regions that undithered quantization would collapse to zero, so the added information can initially cost bits. As resolution and prediction quality improve, that quiet-zone penalty shrinks and the benefits of cleaner reconstructed history can offset it. The exact entropy curves, and whether or where the curves cross, depend on the signal and the predictor: these causal 1D toy prediction algorithms illustrate the mechanisms, while stronger non-causal and higher-dimensional predictors will produce different numerical results.
